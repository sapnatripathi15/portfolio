# Sapna Tripathi Portfolio

Professional portfolio website for Sapna Tripathi, focused on business development, cybersecurity training, enterprise relationships and operations leadership.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages friendly
- No build step

## Local preview
Open `index.html` in a browser, or serve the folder using any static file server.

## Deployment
The repository is ready for GitHub Pages deployment from the `main` branch.

## Privacy
The public website intentionally excludes sensitive personal resume details such as date of birth and marital status.
